# aqi-anomaly-dashboard: interface design

Reference: [mintlify design analysis](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/mintlify/DESIGN.md), curated by VoltAgent. This is an independent adaptation; no affiliation, brand assets or proprietary fonts.

Single light reading workspace. Mint active states, white surfaces, 240px desktop navigation rail and spacious analysis cards. Below 1200px the rail becomes horizontal navigation.

Use local system fonts, 16px body and 14px secondary text. Keep semantic data colors distinct from decorative accents. Preserve data labels, warnings, keyboard focus, chart tables, cancellation and existing route contracts. No external font or asset requests. Mobile controls retain at least 44px height. All pages reflow at 200% text; wide data tables scroll inside named keyboard-accessible regions.
